# 长期记忆（模板）

> 一行一条，前面带日期和标签。这个文件会被注入到她的上下文里，所以别写成长篇小说。
> 建议每周整理一次：合并重复的、把没用的删掉、把「事实」和「推测」分开标。

## 格式
- [YYYY-MM-DD] [标签] 内容

## 标签建议
- [事实]      确定的事（住哪、养什么、在意什么）
- [规矩]      定下来的规则（怎么称呼、能做什么不能做什么）
- [坑]        踩过的坑 + 正确做法（防止重复犯错）
- [能力]      她学会了什么、配置在哪
- [偏好]      你喜欢/讨厌的表达方式

## 示例（改成你自己的）
- [YYYY-MM-DD] [事实] 你在杭州工作，养了一只橘猫
- [YYYY-MM-DD] [规矩] 一律叫我「哥」，不要用别的称呼
- [YYYY-MM-DD] [坑] 改完网页必带缓存戳，不然浏览器一直读旧版
